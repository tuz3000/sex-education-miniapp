Путь пользователя к оформлению

Два режима: независимые касания и действия в строгом порядке по известному ID.

Независимые этапы

Показаны действия, которые удалось распознать в имеющихся событиях.
Пользователи
Важно про оплату. «Нажал оплатить», «Открыл бота» и «Подписка активна» не доказывают успешную покупку. Завершённую оплату показываем только при наличии соответствующего события. Если платёжный сервис не передаёт событие, сумма и число фактических продаж из этой админки неизвестны.

Платёжные и соседние действия

Открытия тарифов, клики, оформление, выдача доступа и подтверждение оплаты.

Что означает эта воронка

  1. Независимые касания - число известных пользователей, выполнивших каждый шаг, независимо от порядка.
  2. «Путь по порядку» - только пользователи с ID и датированными событиями, прошедшие шаги последовательно.
  3. Неизвестные ID и неполные журналы делают охват и конверсию неполными.
  4. Проценты - аналитика записанных событий, а не бухгалтерский отчёт.

Мои рекламные ссылки

Локальный список для удобного повторного копирования. Переносится между устройствами только вручную.
Как трактовать данные: «Старые / без записи» - события, где ещё не сохранялась метка. «Без метки» - новые посещения без startapp. Переход к оплате не подтверждает покупку. Источники будут видны, только если источник записи и источник чтения Apps Script действительно используют одну таблицу.
